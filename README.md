# Complaint Management System Using C++

## Description
A console-based Complaint Management System developed using C++.
It allows users to register, view, search, update, and delete complaints.

## Features
- User Login Authentication
- Register Complaint
- View Complaints
- Search Complaint
- Update Complaint Status
- Delete Complaint

## Technologies Used
- C++
- Structures
- Functions
- Arrays
